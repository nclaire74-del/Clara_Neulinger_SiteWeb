Conversion CV en PDF

Instructions pour convertir en PDF :

  1. Ouvrez cette page dans votre navigateur
  2. Appuyez sur Ctrl+P (Windows) ou Cmd+P (Mac)
  3. Sélectionnez "Enregistrer au format PDF" comme imprimante
  4. Enregistrez le fichier avec le nom approprié :
    • CV_Clara_Neulinger_FR.pdf pour la version française
    • CV_Clara_Neulinger_EN.pdf pour la version anglaise
  5. Répétez pour les deux CV (scrollez vers le bas)
